# 跨模型工作协定

- **Gemini/视觉强模型**：品牌美学、方向板、图组节奏
- **GPT/审计整合**：可证实事实、一致性、交接维护
- **Codex / Cursor**：设计令牌、组件、页面、测试、Visual Loop 运行时
- **Hermes**：本机工具盘点与编排（不重复部署已有环境）
- **人类用户**：品牌取舍、最终审美、付费、发布、合同承诺

## 状态机

`DISCOVERED → RESEARCHED → DIRECTION_APPROVED → DESIGNED → IMPLEMENTED → AUDITED → APPROVED → LOCKED`

未审美批准不得标 LOCKED。

## 避免重复造轮子

`Brand Book ≠ Design System ≠ Visual Factory OS ≠ GEO SOP`
