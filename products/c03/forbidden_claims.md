# C03 禁宣称清单

> 这些参数/功能在产品手册中未定义或不准确，图片中**绝对禁止出现**。
> 违反任何一条 = P0 审计直接失败。
# 数据来源: 交接说明 README_给Work模式.md + 产品手册审核

---

## 永久禁用

| 禁用项 | 原因 |
|--------|------|
| **IP56 / IP65 防水等级** | 产品手册无任何 IP 等级定义，不可宣称 |
| **磁吸功能** | 产品无磁吸结构，不可暗示 |
| **Nano Coating / IML 涂层** | 产品手册无此工艺描述 |
| **夜视功能** | 产品无夜视仪功能，不可宣称（补光灯≠夜视） |
| **自动追踪** | 产品无目标自动追踪功能 |
| **军用 / 战术 / 狙击** | 不可使用军事用途暗示，合规风险 |
| **"全目标保证2000m"** | 2000m 仅限 C03-20 型号且为额定最大量程，非全目标保证 |
| **可见红色激光束** | 905nm 为不可见红外激光，不可画成可见红光 |

## 谨慎使用

| 事项 | 规则 |
|------|------|
| 测角范围 ±1° | 说明书标注 ±1°，但实际设备可显示大角度（如 ∠-19.2°）。图片中不强调角度精度 |
| C03-15 vs C03-20 | 必须标注具体型号，不可混淆。1500m vs 2000m 不可混用 |
| 续航 ≥2.5h | 仅连续测量工作模式，非待机时间 |
| 720P 摄像 | 是摄像分辨率，非显示屏分辨率（显示屏 320×240） |
