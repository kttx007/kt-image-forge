# C03 宣称控制清单（修订版）

> 目标不是“把卖点禁光”，而是区分：**已确认可大胆营销 / 需要精确表述 / 真正禁止夸张**。
> 规则优先级：产品负责人明确确认 + 已审核公司营销资产 + 当前规格资料 > 历史 AI 推演文件。
> 只有出现明确冲突、版本差异或会导致虚假宣传的情况，才升级确认。

---

## A. 已确认，可用于营销设计

| 功能 | 使用方式 |
|---|---|
| **IP65** | 可作为环境适应性卖点；可设计雨雾、水滴、户外工况，但不要做潜水/浸泡式夸张画面 |
| **磁吸** | 可展示磁吸固定/临时固定场景；前提是产品结构和吸附位置按真实营销资产表现，不乱造结构 |
| **WiFi + APP** | 可展示手机互联、记录、查看、分享工作流 |
| **拍照 / 录像** | 可作为核心差异化能力表达 |
| **视频画中画 / Picture-in-Picture** | 可重点用于首图与 Hero 图，提高一眼理解和科技感 |
| **普通夜间/低照度观察** | 可表达夜间/黄昏可用，但不包装成军用级夜视、热成像或极限全黑环境能力 |
| **7X 光学 + 1-6X 数字放大** | 可用于远距观察卖点，注意不要把数字放大写成连续光学变焦 |
| **C03-15 / C03-20** | 可分别宣传 1500m / 2000m，具体图中要对应 SKU |

---

## B. 需要精确表述，不是一刀切禁用

| 事项 | 规则 |
|---|---|
| **2000m** | 仅对应 C03-20；不要写成“任何目标、任何天气必达 2000m” |
| **夜间能力** | 可以做夜景，但定位为普通夜间/低照度观察；不要做军事夜视绿色视野、热成像轮廓等视觉暗示 |
| **IP65** | 可以做雨淋、防尘户外氛围；不要升级成 IP67/IP68、浸水、潜水 |
| **磁吸** | 可展示真实磁吸固定逻辑；如具体吸附面/位置在素材中不清楚，优先参照现有营销图，不凭空造磁铁结构 |
| **精度** | 按具体型号和距离区间表达，不把最佳精度覆盖全量程 |
| **905nm Class 1** | 不画成可见红色激光束；可用抽象测距线/UI，而不是“真实可见激光” |

---

## C. 真正禁止 / 高风险夸张

| 禁用项 | 原因 |
|---|---|
| **IP56** | 当前确认是 IP65，IP56 属错误等级 |
| **IP67 / IP68 / 潜水级** | 未确认，不得升级 |
| **热成像 / Thermal Imaging** | 未确认，不得暗示 |
| **军用级夜视 / 战术夜视** | 与普通夜间观察不是一回事，避免夸张 |
| **自动追踪 / AI 自动锁定移动目标** | 未确认 |
| **军用 / 狙击 / 战术作战用途** | 不做军事用途包装 |
| **全目标保证 2000m** | 量程受目标、天气、反射条件影响 |
| **可见红色激光束** | 905nm 激光不可按可见红光表现 |
| **增删镜头、孔位、按键、接口、屏幕** | 产品结构硬约束，任何变体直接失败 |

## 冲突处理机制

1. **先查已审核营销资产**：中文图、英文图、详情页、视频关键帧、历史成熟主图。
2. **再查说明书和规格表**：用来校准型号、参数和边界。
3. 如果“说明书没写，但负责人明确确认且已有成熟营销资产反复使用”，默认视为**可用但需保持合理表述**，而不是自动禁用。
4. 只有以下情况才向负责人确认：
   - 不同 SKU 明显冲突；
   - 数字参数互相矛盾；
   - 会把普通性能包装成完全不同技术；
   - 会产生结构变体或明显虚假能力。
5. 审计的首要目标是：**守住产品真实性，同时保留营销张力与创意自由。**
