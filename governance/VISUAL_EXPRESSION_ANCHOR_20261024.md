# 视觉表达与恢复锚点

来源：用户 2026-10-24 要求；适用于 HOME、OEMODM 和全部产品套图。

- 没把握的页面布局/OEM/视觉表现，先查优秀案例；记录来源再设计。
- 使用 `guangyan-visual-loop` / `forge/loop` 约束身份、整图生成、审计和归档。
- 原素材是产品身份依据，不是构图限制。允许有目的的裁切、放大、微距、结构演示。
- 场景必须说明实际任务；可见激光须从正确小发射孔沿机身测量轴射向不透明目标。
- 统一石墨/银灰、克制蓝色、真实硬件橙色及字体灯光；在远近、明暗、信息密度间安排节奏。
- 每张先确定买家问题、核心利益和视觉证据。
- 特效表达功能，不能制造防护等级、光学结构、接口、软件界面、认证或性能证据。
- 整套检查：缩略图能辨产品与主利益；全尺寸文字正确；相邻图片表达有变化。

## 产品比例硬门（2026-10-25）

产品轮廓失真为硬性拒绝。身份审计必须分项检查：整体长宽厚及透视；LCD/黑框相对机身占比；主键与副键直径/间距；Logo 带/空白尾段；侧壁/接口/端面；与手/包装比例。漂亮场景或正确文案不可抵消比例失败。
